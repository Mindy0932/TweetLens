方法、边界与项目贡献

01 / 数据与评估

按标准化文本分组后拆分训练与验证集，同文本跨组数量为0。词表、分类器、提取器、聚类和投影只拟合训练数据。分类模型比较是探索实验；后续反复调参需另设最终测试集。

02 / 模型结构

  • 情感分类：TF-IDF（unigram + bigram，最多35,000特征）与逻辑回归；线性SVM和多数类作为比较。
  • 关键片段：根据训练标注学习各情感的片段内外词权重，搜索连续片段（上限12个token）。中性及极短文本返回全文。是透明的基础模型，不是Transformer。
  • 主题探索：TF-IDF + SVD + KMeans（8簇）与二维Truncated SVD。自动主题并非经过验证的语义类别。

在线推理使用同一分类头的 INT8 ONNX 浏览器版本。保存的验证指标来自 Python 实验；量化与运行时会带来数值差异。

03 / 分数如何解释

“已知情感”使用真实标签提取；“自动流程”使用预测标签再提取。两者不能混为同一种实验条件。Kaggle测试文件缺少真实片段，本项目没有报告其提取分数，也没有新的官方排名。

04 / 适用范围

历史英文推文样本不能代表整个平台。没有时间、点赞、转发和用户关系字段，不分析传播效果、时间趋势或社交网络。自动提取片段不是因果解释；概率未独立校准；讽刺、否定等错误原因需要人工复核。

05 / 来源与AI协助

数据来自 Kaggle Tweet Sentiment Extraction。

本版本由AI协助重新实现：新增防重复泄漏的验证流程、分类模型比较、词权重片段提取、主题探索、离线推理、Streamlit应用与文档。作品集应如实注明AI协助，并说明使用者实际完成的复现、修改与分析。新写代码为MIT许可；数据使用遵守来源条款。
